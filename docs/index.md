# Introduction

## Ageless Engineeringとは？

Ageless Engineeringは、株式会社エイジレスの開発組織の「思想」をドキュメント化したものです。我々はまだ小規模な開発組織ですが、AIが当たり前となる時代にどんな技術組織でありたいか・何を大事にしているか・何を軸に判断するか、を生きたドキュメントとして記録し、運用しながら更新していきます。このドキュメントは中長期的な方向性を示すだけでなく、日々の行動の意思決定に使います。

## なぜドキュメント化するのか？

エンジニアの日々の行動や判断の拠り所となる共通の思想がまだ醸成しきれていません。意思決定で揃えるべき軸を言語化し、組織のコアとして共有することが第一の目的です。加えて、AIがエンジニアリングの常識を塗り替えつつある今、誰も正解を確立できていない時代だからこそ、我々はこういうスタンスで技術と組織に向き合うという考えを社内に浸透させ、社外にも発信していきます。

## どう活用していきたいか

### 日々の意思決定の拠り所として

技術的な判断に迷ったとき、設計やレビューの議論で出発点を揃えたいとき、まずこのドキュメントに立ち戻ります。Ageless Engineeringは、個別の正解を与えるものではなく、我々が大事にしている考え方や判断の軸を共有することで、メンバーそれぞれが自律的に意思決定できる土台となることを目指します。

### オンボーディングの起点として

新しいメンバーが開発組織に加わったとき、Agelessの開発組織がどのような思想で動いているかを理解するための入口として活用します。読めば一通り組織のスタンスが掴める状態を、運用しながら育てていきます。

### 採用における相互理解の材料として

Agelessへのジョインを検討している方にも、選考や面談の場面で参照していただきます。我々の思想に共感いただけるかを判断する材料として、また入社後のフィット感を事前に確認していただくための材料として機能させていきます。

### 生きたドキュメントとして

Ageless Engineeringは完成された成果物ではなく、運用しながら更新していく生きたドキュメントです。組織の現在地と思想は時間とともに変わっていくため、現実とのズレに気づいたタイミングで議論し、その都度書き換えていきます。
